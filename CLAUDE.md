## Reglas de trabajo
- Escribir siempre en **español** (España), tono cercano y profesional.
- El contenido (textos, trabajos, perfiles) se cambia en `proyectos.js`; `index.html` solo para diseño.
- Proyectos nuevos: usar las categorías y el formato descritos en `proyectos.js` y la fórmula **Reto → Lo que hice → Resultado** (con una cifra siempre que se pueda).
- No inventar datos ni cifras: los valores `XX` / `EJEMPLO` son marcadores a sustituir por datos reales que dé Antonio.
- Sin dependencias ni build: la web debe seguir funcionando abriendo `index.html` tal cual.
- Cualquier diseño o pieza para la marca personal sigue la skill `marca-personal`.
