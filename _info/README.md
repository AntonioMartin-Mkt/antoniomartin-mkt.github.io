# _info · Información para el portfolio

Aquí va todo lo que sirve para **escribir y mantener** el portfolio, pero que no forma parte de la web:
textos en borrador, datos para el CV, cifras y resultados de cada trabajo, notas, ideas, enlaces de referencia.

**Esta carpeta no se publica en la web.** GitHub Pages ignora las carpetas que empiezan por guion bajo (`_`),
así que nada de aquí aparece en `antoniomartin-mkt.github.io`.

**Pero el repositorio es público:** cualquiera puede abrir esta carpeta desde GitHub.
No guardes aquí nada privado (DNI, teléfono personal, contraseñas, datos internos de la empresa de prácticas).

## Cómo organizarla
- `pendientes.md` → lo que falta para que el portfolio esté completo.
- Un archivo por tema cuando haga falta, por ejemplo:
  - `perfil.md` → textos de «Sobre mí», propuesta de valor, habilidades.
  - `cv.md` → formación, experiencia y datos para el CV.
  - `trabajos/<nombre-corto>.md` → reto, lo que hice, resultado y cifras de cada trabajo antes de pasarlo a `proyectos.js`.
